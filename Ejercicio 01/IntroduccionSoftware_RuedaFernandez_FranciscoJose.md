## 1. ¿Qué es un programa informático? 
Un **programa informático** es un conjunto de instrucciones escritas en un lenguaje de programación que se ejecutan y realizan tareas específicas en un ordenador o sistema informático.
## 2. Diferencia entre código fuente, código objeto y código ejecutable
* **Código fuente:** Es el conjunto de instrucciones escritas directamente por el programador utilizando un lenguaje de programación de alto nivel. Es comprensible para las personas.
* **Código objeto:** Es el resultado de traducir o compilar el código fuente a lenguaje máquina o formato binario intermedio, aunque aún no constituye un programa totalmente autónomo. 
* **Código ejecutable:** Es el código final procesado y enlazado, preparado para ser ejecutado de forma directa por el sistema operativo y el procesador.
## 3. Etapas del desarrollo del software El ciclo de vida del software comprende las siguientes fases fundamentales: 
1. **Análisis:** Documentación previa orientada a entender y comprender de forma detallada el problema a resolver.
2. **Diseño:** Definición de cómo se va a resolver el problema, determinando las estructuras de datos, lenguajes de programación y la arquitectura del sistema. 
3. **Codificación:** Fase en la que se convierte el diseño previo en código fuente ejecutable. 
4. **Pruebas:** Fase en la que se establecen criterios concretos y se comprueba su cumplimiento para garantizar la calidad. 
5. **Mantenimiento:** Tareas dedicadas a adaptar y mejorar el sistema frente a nuevos cambios o para corregir errores tras su despliegue. 
&gt; *Nota:* Una documentación adecuada y de calidad es necesaria en todas y cada una de las fases del ciclo de vida.
